# r96 Adjudication - Pulse CLI And Cork

DECISION: **ADMIT-with-findings + required fold** on `7358f13b`, excluding
the false option-position law and unsupported negative-witness claims.
The implementation is not certified for unattended use before those
coverage defects are repaired.

## Five-Gate Record

- Verifier: two archived committed-byte runs reproduce 178 legs each;
  its independent 509-check set reports 507 passes and two named blocks
  per receipt. The blocks concern `e_native_corked`'s projection, not
  evidence of a silently successful measurement. Live cork/readout
  re-derivation and mutation/forgery controls discriminate.
- Critic and reviewer independently confirm that `pactl info -s SERVER`
  ignores the post-subcommand server option here. rc 0 therefore does
  not prove the requested server was used.
- Reviewer confirms the trigger/prebuffer predicates accept dead or
  absent capture witnesses; successful recorded taps do not repair
  those predicates. Witness helpers also omit the subject environment.
- Scribe confirms family/dispatch copy identity and receipted numbers.
  The reported foreign-sandbox `pkill` incident is attestation-only:
  neither the exact signal operation nor its ownership check survives
  in a receipt. Do not promote that disclosure to independently
  reconstructed incident evidence.
- Simplifier proves a duplicate-cell deletion and a pid-keyed witness
  repair on scratch trees. Deleting the witness instead is explicitly
  held because it abandons, rather than enforces, the no-stream claim.

## Required Fold

1. Reject the option-position interpretation. Compare a resolved server
   identity using controlled distinct endpoints; a successful default
   connection is not evidence that a requested endpoint was honored.
2. Require live, nonempty monitor capture and checked tap status before
   interpreting zero frames/energy as trigger/prebuffer stall. Missing
   capture is unmeasured or failed, never a successful negative.
3. Give snapshot readers the exact subject environment so `PULSE_SERVER`
   cannot split subject and witness.
4. Record the spawned child's pid and key both no-stream lookups to it,
   not pid 0. Preserve both refusal-class and stream-absence witnesses.
5. Remove the proven duplicate only with an explicit census correction.
   Do not report the proposed folded count as today's count.
6. Label TCP-4713 outcomes as current host state, not universal client
   behavior. Correct stale leg counts, latency range and cork-projection
   prose; retain the named block for host-dependent projection.

Admit the measured attribute/cork/flow observations at the scope supported
by the verifier's receipts. Reject C1's interpretation and the assertion
that every negative capture arm already enforces witness liveness.
No source, instrument, threshold, pin or simplifier change accompanies
this adjudication. The five wave-B reports retain the full evidence,
limitations and proposed repairs.
