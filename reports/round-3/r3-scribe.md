# Round 3 scribe: local decision table and limits

## Decision-table proposal (not an integrated test result)

Round 3's declared move is depth, not a change to the set of assets. The baseline entry point measures nine WAVs (eight SFX and one stem); the three looping fixtures are `ambience`, `ambience_alt`, and `stem`. In the current `measure_audio.py`, the loop criterion is only `abs(samples[0] - samples[-1]) <= 0.03`; it does not compare adjacent differences. This table proposes keeping that check and adding an explicitly local decoded-PCM slope-join proxy. The slope threshold below is a proposal derived from the clean fixtures and must be reconciled with `r3-metric` / `r3-calibration` and tested by the non-author verifier before any admission claim.

## Provenance and boundaries

The three slope values above were calculated by reading the existing `.shokunin/audio/corpus/artifacts/{ambience,ambience_alt,stem}.wav` as mono 16-bit PCM and dividing integer samples by 32768 before taking adjacent differences. This was a Python in-kernel read/calculation; I ran no shell command (so there are no shell command/exit-code receipts for this report). The artifact-generation and measurement methodology is described in `corpus/knowledge/2026-10-12-fixture-battery.md`; the independent round-2 numeric baselines are in `reports/round-2/r2-verifier.md`. Those reports establish fixture context, not round-3 evidence.

The proposed slope metric compares first differences at the two ends of one decoded, presumed-periodic buffer. It is not a derivative estimate over a window, phase continuity test, playback test, codec/runtime loop test, or perceptual seam judgment. Its numerical bound is sample-rate and fixture specific. The probe tests a crafted control only. Even if the proxy is integrated and independently replayed, the defensible result is only that the added local numeric check detects that control while clean fixtures and prior guards pass. No perceptual quality, production-readiness, mastering, rights, or publishing claim follows. No borrowed samples or listening claims are involved.
