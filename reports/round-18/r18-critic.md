# Round 18 critic — quantized 200 Hz slope probe

## Scope and evidence

I inspected the round-18 declaration in `.shokunin/audio/LOG.md`, `corpus/fixtures/measure_audio.py`, `corpus/fixtures/build_artifacts.py`, and the canonical `corpus/artifacts/stem_layer_third.wav`. I did not modify or execute source, builder, or runner code, and did not generate a candidate WAV. Shell commands/exits: **none**. This is an independent source/PCM arithmetic critique, not a runner result or a candidate-fit claim.

The decoded canonical WAV is mono PCM16, 48 kHz, 192,000 frames. Around the section join (frames 95998–96001) its integer samples are `[-26, -13, 0, 43]`. The adjacent slopes are +13 and +43 counts, so the side-slope mismatch is **30 counts**. The runner's strict failure predicate is `slope_delta > .001` full scale/sample; with the measurement path's float conversion this corresponds to a 32.768-count limit. Thus baseline is 30/32768 = **0.00091552734375**, passing by **2.768 counts**, or **0.00008447265625 FS/sample**. This baseline is already close to the threshold; it is not robust headroom.

## Falsification: +8 counts and quantized sign

Applying the declared operation to a copy of the canonical PCM (`frame 96001 += 8`, so `43 → 51`) yields join samples `[-26, -13, 0, 51]`. The right-minus-left slope becomes 51−13 = 38 counts, so absolute side-slope mismatch is **38 counts / 32768 = 0.00115966796875 FS/sample**. This exceeds the unchanged `.001` gate by **5.232 counts**, or **0.00015966796875 FS/sample**. The increment's **positive sign matters**: it increases the right-hand slope and moves the candidate farther into failure. The matching negative change would reduce the mismatch instead. The nearest failing integer mismatch is 33 counts; from baseline 30, a +3-count change is already enough to fail, while +2 produces 32 counts and still passes. Therefore +8 is not a marginally necessary quantized perturbation; it overshoots the first failing integer by five counts, although its absolute distance beyond the threshold is still small.

On this exact sample edit, the join adjacent-value jump remains 13 counts (**0.000396728515625 FS**) and the outer side-slope remains 30 counts (**0.00091552734375 FS/sample**), since frame 96001 is not an outer endpoint. The section FFT-bin measurements are unaffected at meaningful precision: the component is 200 Hz (bin 400 for each 96,000-sample half), with amplitudes approximately `.0149999849` and `.0499980392` FS and signed contrast **+10.457243 dB**, above the 6 dB gate. These are calculations from the decoded canonical PCM with only that one count edit; they are not a decoded candidate receipt. They falsify no claim that the specified edit will cross the internal slope gate, but they do constrain the claim: the intended local failure is internal side-slope only, not outer slope or join-gap, and must be confirmed on the actual generated probe.

The word “sole” needs this scope. The source's `section_contrast()` returns `passed` based on section amplitude validity and contrast only; it does **not** include the internal join-gap or side-slope in that `passed` field. Separately, `measure()` checks outer endpoint and outer side-slope. So a runner mode that reports one slope failure must be described by the complete receipt and the separately evaluated checks, not just by `section.passed` or a flattened failure list. Also, this edit changes one decoded sample, not an isolated abstract property: it necessarily changes local waveform data. “Slope-only” is an operational statement about which named numeric predicate crosses, not that all waveform properties are invariant.

It writes the 200 Hz canonical fixture but currently implements slope probes for the prior 120 Hz and 180 Hz fixtures only. I made no setup attempt; there is no failed setup to count as evidence. Until the parent integrates the opt-in mode, the proposed argument is a design calculation, not a runnable or passed probe. Do not infer 14-mode replay or unchanged old modes from this source review.

The full-waveform centroid and per-section 200 Hz bin amplitude are deterministic numeric proxies. A one-bin amplitude floor/ratio, sample-level slope, endpoint jump, and broad centroid band do not establish audibility, smoothness, musical quality, listener discrimination, engine behavior, or production performance. No threshold change is warranted by this critique. Recommended report wording: **the +8-count PCM hypothesis predicts an internal side-slope failure at 38 counts, while leaving the named gap, outer-slope, and section-contrast checks on their passing side; this remains unverified until an actual probe receipt demonstrates the full failure set.**
