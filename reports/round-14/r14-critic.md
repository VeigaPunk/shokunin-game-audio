## Ways the gap-only claim can be overstated

- The target is an index-specific PCM sample difference: `abs(samples[96000] - samples[95999]) > .03`. It proves only that the decoded samples at this particular boundary cross this existing numeric threshold. It does not test all boundaries, interpolation/reconstruction behavior, a perceptual click, or a musical transition.
- The side-slope value is a discrete second difference across the center: `abs((x[96001]-x[96000])-(x[95999]-x[95998]))`. Setting `x[96001]` can cancel it algebraically while retaining a large `x[96000]-x[95999]` step. Thus “slope passes” is not independent evidence that the discontinuity is inaudible; the two probes inspect coupled local samples. The condition does not constrain the two local first differences separately or inspect a window around the edit.
- The gap comparison is strict `> .03`, and source generation is PCM16 rounded/clipped. One PCM count is `1/32767 ≈ 0.00003052` FS; the smallest integer-count magnitude above .03 is 984 counts (`984/32767 ≈ .03003`). A target just over threshold is particularly sensitive to quantization and to ffmpeg/sox decoding. Report decoded measurement, not just the intended floating-point recipe. Likewise slope acceptance is strict `> .001` (roughly 33 PCM counts/sample to exceed it), so report the measured post-quantization side-slope value and margin.
- A “sole failure” is true only for the exact built artifact and runner receipt: generic checks include level, format, duration, and whole-file centroid; the section gate includes FFT-bin contrast/validity; the runner conditionally applies gap and slope gates by fixture name. State every emitted failure list. Passing a centroid band or section-bin ratio says nothing about local smoothness: a one-sample perturbation contributes broadband energy but can be diluted in whole-file statistics. Neither metric authenticates a perceptual property.
- Frame 96000 is the half-file join only for exactly 192000 decoded samples at 48 kHz. Section count currently ensures that length for section contrast, but changes in duration/decode path or an off-by-one edit can put a perturbation somewhere other than the intended join. Confirm the generated WAV frame count and inspect decoded samples 95998–96001 when assessing isolation.

## Falsification / reporting requirements

Reject the “gap-only” result if the chosen exact artifact has any other runner failure, the post-decode gap is not strictly above `.03`, the post-decode side-slope is above `.001`, or section contrast / validity fails. Also reject the stated 180-Hz experiment if its candidate or runner actually uses the 120-Hz `stem_layer` path. A low margin or a result dependent on an undocumented sample edit is a fragile threshold demonstration even if numerically sole-failing; record it as such rather than as robust evidence.

Even a clean sole-gap failure supports only the narrow statement that this deterministic synthetic PCM probe isolates the existing adjacent-sample-gap branch under the runner’s definitions. It does **not** establish audible click/pop, perceptual audibility, musical suitability, engine behavior, security, or production quality. I made no audible or engine claim and changed no threshold.
