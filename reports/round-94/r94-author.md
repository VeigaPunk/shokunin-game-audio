### 1. `sox_det_r94_probe` — the precision-tracking law (headline)

- **Auto-dither is a precision consequence, not a dither option.** Measured
  distinct-sha counts over fresh processes: default `gain -6` **5/5**,
  `-D gain -6` **1/3** (byte-stable, and its bytes equal the scout's
  `gain_D.json:gain_m6` sha), explicit `dither` **5/5**, `-D dither` **5/5**
  (so `-D` does *not* fix an explicit dither), `-R dither` **1/3**, and
  `-R -D dither` is byte-identical to `-R dither`.
- **The `< 24` output-precision clause**: f32→s16 **5/5 distinct**, f32→s24
  **1/5**, f32→s32 **1/5**, s16→s24+gain **1/3**.
- **Integer/unity operations are byte-identical to the input**: `gain 0`,
  the **no-effect pass-through**, `rate 48000`, `pad %50` (4/4 shas equal to
  the stimulus sha).
- **Flag order is inert**: `-D` before infile / after infile / after outfile,
  `--no-dither`, `-D -R`, `-R -D` → one sha; a global option placed *after*
  the effect refuses rc 1 (`sox FAIL gain: usage: …`,
  `sox FAIL dither: invalid option \`-R'`).
- **`--buffer` / `--input-buffer` are inert** (1024/4096/16384/4096 → one
  sha), and **the client env is inert** (10 variants: `PIPEWIRE_QUANTUM`,
  `PIPEWIRE_RATE`, `PIPEWIRE_LATENCY`, `PIPEWIRE_NODE`, `PULSE_SINK`,
  `PULSE_SOURCE`, all-at-once → one sha) — a file transform never opens a
  device.
- **Concurrency**: 16 simultaneous `-D gain -6` → **1/16** shas;
  16 simultaneous `-R dither` → **1/16**; 16 simultaneous *default* `gain -6`
  → **16/16** (nondeterminism is a property of the effect, not of the load).
- **CORRECTION (this seat):** `copy` is **not** an effect on this build —
  `sox in.wav out.wav copy` parses the token as a **third positional** (the
  multi-input concatenation grammar) and refuses **rc 2**
  ``can't open input file <out>``. The scout's D10 row ("`copy` is
  byte-identical to the input") was measured with **no effect token at all**;
  that pass-through identity is armed as `det_passthrough_identity`, and the
  `copy` token is disarmed as an effect name (`det_copy_token_not_an_effect`).

### 2. `sox_gain_r94_probe` — rounding and chain order (all `-D`)

- `gain -6` mismatch vs `rint(x·10^(−6/20))` = **0** (peaks
  `[−12.0211, −18.0406]`); `gain 6` on the mono stimulus = **0**.
- `vol 0.5` (amplitude) → mismatch vs **ceil** = **0**, vs rint = **23 000**
  — the amplitude form is a ceil path.
- `vol -6.0206 d` and `vol 0.5 p` → mismatch vs **rint** = **0**.
  **CORRECTION:** the `p` form is a *power* ratio, i.e. amplitude
  `sqrt(gain)` = −3.0103 dB (the scout's row does not state the factor; the
  measured peaks `[−9.0311, −15.0509]` vs the amplitude form's
  `[−12.0412, −18.0618]` are exactly 3.01 dB apart).
- **The two `vol` spellings are not interchangeable**: `vol 0.5` vs
  `vol -6.0206 d` → different bytes, **23 000** differing samples, max abs
  diff **exactly 1 LSB**.
- Global `-v 0.5` is byte-identical to `vol 0.5` (same ceil path).
- `gain -n` normalizes the file peak to `[0.0, −6.0206]` (one factor for both
  channels, warning `output clipped 1000 samples`); `gain -e` and `gain -b`
  both lift to `[−6.0206, −6.0206]` and are the same bytes.
- **`-G` is not a limiter**: under `-D`, `gain 12` and `-G gain 12` both rail
  **30 000** samples at the ≥ 32 766 threshold (the byte streams differ, the
  railed count does not). The scout's ≥ 32 767 row is dither-sensitive and is
  *recorded only* (see entry 8).
- **Effect order is content-visible**: `gain -6 norm -3` ends at
  `[−2.999988, −9.020588]`; `norm -3 gain -6` at `[−8.999645, −15.020992]`.

### 4. `sox_remix_r94_probe`

- `remix 1` **selects** channel 1 (mismatch 0 vs L; 47 000 samples differ from
  `(L+R)/2`).
- The auto downmix is `floor((L+R+1)/2)` (mismatch 0; 17 000 samples differ
  from the nearest-even mean), `channels 1` is the **same bytes**.
- `-m 1,2` = exact `L+R`; `-p 1,2` = `rint((L+R)/√2)`; `remix 2 1` swaps;
  `remix 1 0` = `[L, 0]`; `remix 1v0.5 2v0.5` is the **same bytes as
  `vol 0.5`** (the v multiplier is the amplitude/ceil path); `remix 1p-6`
  applies exactly −6 dB (`[−12.0211]`); `remix 1 1` duplicates mono→stereo.
- **CORRECTION (naming):** `remix 0 1` is `[silence, input-1]` = `[0, L]`
  (peak `[−inf, −6.0206]`), because the *N*-th spec argument describes the
  *N*-th **output** channel and its number names an **input** channel. The
  scout's receipt calls that row `remix_right_only`; the semantics are pinned
  here as `remix_0_1_zero_then_in1`.

### 5. `sox_trim_r94_probe`

- Forms: `trim 0 0.1` → 4 800 (sample-exact: mismatch 0 vs the input head);

### 6. `sox_fade_r94_probe`

  `fade 0 0.15 0.1` → **7 200** frames, `fade 0 0.2 0.05` → **9 600**,
  `fade 0 0.25 0.1` → **12 000**.
- **The log curve is exactly 100 dB per span**: measured out/in at

  quantized samples).
- Curve table re-measured as out/in ratios at x = .25/.5/.75 and armed within

  `t` 0.2499/0.5000/0.7500, `p` 0.4375/0.7500/0.9375, `s` 0.0625/0.2500/0.5625.
- **The default type is `l`** (`fade 0.1` ≡ `fade l 0.1`, identical bytes);

### 7. `sox_repeat_pad_silence_r94_probe`
